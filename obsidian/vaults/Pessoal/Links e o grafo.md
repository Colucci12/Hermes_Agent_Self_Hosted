# Links e o grafo

O pulo do gato do Obsidian é o link interno:

```
[[Bem-vindo]]
```

Isso cria uma conexão entre esta nota e a nota **Bem-vindo**. Com o tempo, o painel **Graph view** (ícone de molécula na barra esquerda) desenha essas conexões.

Experimente:

1. Crie uma nota nova (`Ctrl+N`).
2. Escreva um link para [[Bem-vindo]].
3. Abra o Graph view e veja o ponto novo aparecer.
